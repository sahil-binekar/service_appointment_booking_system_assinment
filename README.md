Task
Build a Service Appointment Booking System where customers can book appointments with service providers.

Duration:- 3 hours

The application must support:

# JWT-based login with Admin, Provider and Customer roles.✅️
# Providers can define their working hours and available slots.✅️
# Customers can view available slots and book appointments.
# A provider must not be double-booked, even if two booking requests arrive simultaneously.
# Customers can cancel only their own appointments.
# Implement appointment statuses: Pending, Confirmed, Completed, Cancelled.
# Create a mock payment flow with Pending, Success, Failed and Refunded states.
# Create a React dashboard for customers and admins.
# Admin should be able to search, filter and paginate appointments.
# Create an admin dashboard API showing total users, providers, appointments, cancellations and revenue.
# Implement proper API validation, authorization, HTTP status codes and error responses.
